  - Python >= 3.11
  - Node.js >= 22.12 et npm (Electron verrouille cette version minimale)

6. DONNEES LOCALES
--------------------------------------------------------------------------------
Dossier data/ : INEXISTANT (gitignore, non cree)
Mode portable (portable.json) : data/ serait a la racine
Mode installe (sans portable.json) : ~/.local/share/thot/data (XDG)
Arborescence data :
  database/   (thot-phase-1.db — 25 tables + schema_migrations + 2 tables FTS)
  blobs/      (adresses par contenu, dedupliques : sharding <2 hex>/<sha256>.bin
               au depot, plus <sha256><ext> a plat des chemins historiques)
  logs/       (journaux du sidecar)
  temp/       (volatil ; temp/staged/ pour le staging des pieces jointes)
  staged/     (effets image : <effect_id>.png — backend/tools/generate_image.py)
  backups/    (sauvegardes)
  derived/    (figures/ extraites, reconstruites a la demande —
               backend/ingestion/figures_etape.py)
Pas de previews/ (les vignettes sont reconstruites a la demande), pas de
trash/ (la corbeille est un etat SQL, backend/search/trash.py), pas de
models/ (les poids vivent dans models/, a la racine de l'application, HORS
data/).
Base de donnees : SQLite WAL, thot-phase-1.db (25 tables métier +
                  schema_migrations + 2 tables FTS)

8. COMMANDES DE DEMARRAGE / TESTS
--------------------------------------------------------------------------------
Lancement :
  Linux  : ./lancer-linux.sh
  macOS  : double-clic sur lancer-macos.command
  Windows: double-clic sur lancer-windows.bat

Developpement :
  npm run dev                 (Electron + frontend)
  npm run dev:web             (frontend seul, Vite)
  npm run start               (production)

Tests :
  python3 -m pytest tests/backend/     (marqueurs slow exclus par defaut)
  npm run test:electron                (tests Electron)
  npm --prefix frontend run test       (tests frontend)

Integrite depot :
  npm run depot:verifier   (verifier l'integrite du depot)
  npm run depot:reparer    (reparer le depot)
  npm run depot:gc         (nettoyage / GC)
