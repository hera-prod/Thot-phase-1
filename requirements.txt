# Recherche sémantique — ColBERT (`backend/search/vectors.py`). `transformers` était
# déjà IMPORTÉ par le dépôt (PaddleOCR-VL, encodeur de texte FLUX) sans être
# DÉCLARÉ : une installation par ce fichier ne pouvait donc pas démarrer l'OCR. Il est
# déclaré ici pour cette raison autant que pour ColBERT.
# La version est celle qu'exige le worker PaddleOCR-VL (`models/README.md`), pas un
# choix de la tâche 2.5 : deux versions dans un sidecar PyInstaller, c'est deux
# moteurs de tokenisation qui divergent sur le même texte.
transformers>=4.56,<6
# `huggingface_hub` est la dépendance de `from_pretrained`. Le modèle est lu dans
# `models/` et jamais sur le hub (off-ligne), mais la bibliothèque reste requise au
# chargement — d'où la déclaration, pour que `pip install -r requirements.txt` suffise.
huggingface_hub>=0.34

# Tableurs : openpyxl (voie principale xlsx, valeurs via data_only) + pandas
# (repli xlsx/ods). Déclarés car importés par backend/ingestion/sheets.py.
# odfpy est le moteur .ods de pandas : SANS lui, `read_excel` lève un ImportError
# et un `.ods` revenait vide — donc « ingéré » sans rien avoir lu.
# xlrd n'est PAS déclaré, et c'est délibéré : un `.xls` est un conteneur OLE2 que
# le dépôt refuse déjà à l'entrée (signature inconnue), donc le lire ici
# annoncerait une capacité que Thot ne sait pas délivrer. Voir
# `sheets._motif_classeur_illisible` pour le refus explicite qui remplace cela.
